# ai-course-projects

Coursework from my university AI/ML course (B.Sc. Computer Science). These are the algorithms I implemented by hand to learn how they actually work — no ML libraries doing the thinking for me.

## What's inside

| File | What it does |
|---|---|
| `knn_from_scratch.py` | k-Nearest Neighbors classifier implemented from scratch (stdlib only), evaluated on a synthetic 2D dataset with a train/test split. |

## Run it

```bash
python3 knn_from_scratch.py
```

Sample output: test accuracy for k = 1, 3, 5 on 200 generated points.

## What I learned

Distance metrics, the bias/variance tradeoff in k, and why feature scaling matters — the kind of fundamentals I reach for when working with LLMs and AI tooling in my own projects.
